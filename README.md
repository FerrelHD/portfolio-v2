## 🌟 Overview

Welcome to my personal digital portfolio repository. Designed with an editorial, Awwwards-inspired aesthetic influenced by [Khanh Nguyen](https://khanhnguyen.design), this portfolio showcases a multi-disciplinary engineering journey across **modern full-stack web applications**, **quantitative machine learning models**, and **interactive 3D simulations**.

Built with a focus on fluid 60 FPS motion, seamless horizontal parallax scrolling, macOS-style browser mockups, and type-safe architecture.

---

## ✨ Key Design & Architectural Highlights

- **Horizontal Chapter Narrative**:
  - **Intro / Hero**: 5-stage sequential loading counter (`2022 → 2026`), synchronized mirror-masked exit, and warm bronze curtain transition (`#262220 → #3A3632`).
  - **Chapter I — About Me**: Quick intro, responsive portrait showcase, and creative engineering philosophy with justified editorial typography.
  - **Chapter II — The Work**: Multi-slide project showcase (`#01` to `#04`) featuring macOS browser mockups and curtain-reveal copywriting.
  - **Chapter III — Capabilities & Services**: Detailed engineering disciplines spanning Full-Stack, Machine Learning, and 3D Game Development.
  - **Chapter IV — People**: Collaborations, mentors, and fellow creators.
  - **Chapter V — Contact**: Closing section with live Depok/Jakarta time (GMT+7), direct communication channels, and social links.
- **Editorial Rail & Dynamic Theme Sensing**:
  - Persistent vertical left rail on desktop (compact top bar on mobile) featuring a staggered kinetic SVG hamburger menu.
  - Fullscreen sliding curtain menu with staggered line reveals.
  - Physical bounding-box collision detection that dynamically adapts sidebar colors between light (`#faf9f6`) and dark (`#3A3632`) modes without text color mismatches.

## 💻 Local Development Setup

To run this portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/FerrelHD/portfolio-v2.git

# 2. Navigate to project root
cd portfolio-v2

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

The application will be accessible at `http://localhost:5173/`.

---

## 📦 Build for Production

To create an optimized production build:

```bash
npm run build
```
